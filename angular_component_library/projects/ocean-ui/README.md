# Ocean UI Component Library

Angular Material-based component library following the "Ocean Professional" minimalist theme.

Components included (initial set from Figma screen 87):
- OceanToolbar
- OceanSidebar
- OceanButton
- OceanInput
- OceanSelect
- OceanTabs
- OceanTable
- OceanBadge

Usage:
1. Install peer deps (Angular 19, Angular Material, CDK with exact same versions).
2. Import OceanUiModule or individual standalone components from the library.
3. Ensure the theme stylesheet is included globally.

Storybook is configured under `.storybook/`. Run:
- npm run storybook
